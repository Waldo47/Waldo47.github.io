# Waldo47.github.io

Portfolio de Guido Martin Gallego Paolucci, publicado en https://waldo47.github.io

Sitio estático en HTML/CSS, sin Jekyll (ver `.nojekyll`).

- `index.html`: contenido de la página
- `styles.css`: estilos
- `assets/`: GIFs, capturas, favicon

Para agregar un proyecto, copiá un bloque `<article class="project">` en `index.html`.
Los `<mark class="todo">` resaltados en amarillo son texto pendiente: completalos antes de compartir el link.
